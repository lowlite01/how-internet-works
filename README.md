# Как устроен интернет — интерактивный учебник

Визуальный учебник на русском языке. Анимации показывают, как запрос из твоего кода доходит до сервера и обратно.

На 17 экранах разобраны DNS, HTTP, TCP/UDP, IP, MAC, порты, NAT, DHCP, TLS и HTTPS, VPN, firewall, коммутатор и роутер, модели OSI и TCP/IP, SSH и CI/CD. Есть ещё имитация терминала с `ping`, `traceroute` и `nslookup` и пошаговая диагностика «не открывается сайт».

Все схемы сети построены на одной общей сети: дом (роутер с Wi-Fi, коммутатором, NAT и firewall внутри), провайдер (узел доступа, DNS, кэш видео), интернет (точка обмена и магистрали), дата-центр (защита от DDoS, балансировщик, серверы). Её можно смотреть коротко или «как на самом деле». Главный экран «Путь запроса» проводит по ней четыре примера — видео на YouTube, первое открытие сайта, запрос программы к API погоды и к Claude API — с «Анатомией пакета» (слои TLS, TCP, IP и Wi-Fi-кадр вокруг сути запроса). Вывод traceroute в мини-терминале совпадает с этой же схемой.

Раздел «Расширенный уровень»:
- **карта всех протоколов** — около 30 штук (ARP, BGP, QUIC, HTTP/2 и HTTP/3, WebSocket, SMTP, NTP, MQTT и другие) с портами, уровнями и поиском;
- **экран «Защита и безопасность»** — шифрование и центры сертификации, Wi-Fi (WPA2/WPA3), DNSSEC/DoH/DoT, «сторожа» трафика с анимацией (firewall, WAF, IDS/IPS, прокси, балансировщик), типичные атаки и защита от них (на уровне идеи), вход и права (хеширование, 2FA, OAuth, JWT, CORS, Zero Trust).

- Каждый термин в тексте — кликабельная «таблетка». По нажатию открывается объяснение: что это, зачем нужно, как работает, аналогия, что будет без него, связанные термины. Есть простой и подробный режим.
- Легенда цветов кликабельна: подсвечивает выбранный слой прямо на схеме.
- Работает на телефоне. На узком экране снизу появляются навигация и выдвижные панели. Страницу можно добавить на главный экран (PWA), после первого открытия она работает без интернета.
- Если в системе включено «уменьшение движения», анимации отключаются.

Без сборки и зависимостей: обычные HTML, CSS и JavaScript.

## Как открыть локально

**Способ 1.** Двойной клик по `index.html`. Учебник откроется в браузере, интернет не нужен.

**Способ 2 (локальный сервер).** Нужен, чтобы проверить PWA и офлайн-режим:

```bash
npx serve .
```

Затем открой адрес, который покажет команда (обычно http://localhost:3000).

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы, иконки, панели |
| `style.css` | тёмная тема, адаптивная вёрстка |
| `data.js` | **все тексты**: экраны, шаги анимаций, словарь терминов `TERMS`, глоссарий |
| `app.js` | логика: анимации, таблетки терминов, панель объяснений, навигация |
| `manifest.webmanifest`, `sw.js`, `icons/` | установка на телефон и работа без сети |

Чтобы поправить текст или добавить термин, достаточно отредактировать `data.js`. Новый термин из `TERMS` автоматически становится таблеткой везде, где встречается в тексте.

Сайт опубликован на GitHub Pages.

## Как открыть на телефоне

Открой ссылку на сайт в браузере телефона. Чтобы учебник открывался как приложение (и без интернета):

- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» или «Установить приложение».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».
